**현장의 경험이 회사의 자산이 됩니다.**

HiveTalk 데스크톱 앱의 공식 릴리즈 저장소입니다.
설치 파일 배포와 자동 업데이트 피드를 담당하며, 소스 코드는 비공개 저장소에서 관리됩니다.

### 다운로드

| 플랫폼                | 설치 파일                                                                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Windows (64bit)       | [HiveTalk-x64.exe](https://github.com/hiveworks-app/hive-talk-desktop-app-release/releases/latest/download/HiveTalk-x64.exe)     |
| macOS (Apple Silicon) | [HiveTalk-arm64.dmg](https://github.com/hiveworks-app/hive-talk-desktop-app-release/releases/latest/download/HiveTalk-arm64.dmg) |
| macOS (Intel)         | [HiveTalk-x64.dmg](https://github.com/hiveworks-app/hive-talk-desktop-app-release/releases/latest/download/HiveTalk-x64.dmg)     |
| Linux (Ubuntu/Debian) | [HiveTalk-amd64.deb](https://github.com/hiveworks-app/hive-talk-desktop-app-release/releases/latest/download/HiveTalk-amd64.deb) |

위 링크는 항상 최신 버전을 가리킵니다. 전체 버전 이력은 [Releases](https://github.com/hiveworks-app/hive-talk-desktop-app-release/releases)에서 확인하세요.

### 설치 안내

- **Windows** — Setup 실행 시 별도 선택 없이 자동 설치 후 앱이 바로 실행됩니다. SmartScreen 경고가 뜨면 `추가 정보 → 실행`을 누르세요.
- **macOS** — dmg를 열어 HiveTalk을 Applications 폴더로 드래그하세요. 첫 실행은 우클릭 → 열기.
- **Linux** — deb 파일을 더블클릭해 소프트웨어 센터로 설치하세요.

### 자동 업데이트

한 번 설치하면 이후 버전은 자동으로 적용됩니다 — 이 페이지에 다시 올 일은 없습니다.

| 플랫폼  | 적용 방식                                          |
| ------- | -------------------------------------------------- |
| Windows | 백그라운드 다운로드 후 재시작 시 1~2초 내 전환     |
| macOS   | 백그라운드 다운로드 후 앱 종료 → 다음 실행 시 적용 |
| Linux   | 자동 업데이트 미지원 — 새 버전은 위에서 재설치     |
